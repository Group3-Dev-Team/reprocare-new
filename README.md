# ReproCare

Starter repository for the ReproCare team project.

This is a **non-functional skeleton**: source files are intentionally empty.
React, FastAPI, PostgreSQL and the data-collection bot will be implemented progressively on team feature branches.

No dependencies have been installed or specified. Developers should add their dependency manifests and tests as features are implemented.

## Workflow

Create a task branch from `main`, commit the actual implementation, and open a pull request back to `main`.

Do not commit `.env` files, API keys, browser profiles, databases, or generated build outputs.
